# Growing Artificial Societies · Sugarscape

Интерактивная лаборатория по книге **Joshua M. Epstein, Robert Axtell — Growing Artificial Societies (1996)**. Реализованы первые опыты для *Life and Death on the Sugarscape* и *Sex, Culture and Conflict*.

**[Открыть WASM-версию в браузере](https://olegdurandin.github.io/growing-artificial-societies/)**

Один интерфейс и одно ядро на Rust для настольного приложения и страницы WebAssembly. Графический стек такой же, как в [RustEmu8086](https://github.com/OlegDurandin/RustEmu8086): **egui / eframe 0.37 + wgpu**, веб-сборка через **Trunk**. Рендеринг в браузере: WebGPU с WebGL2 fallback, предоставляемым eframe.

## Запуск

Нужен актуальный stable Rust (проверено на 1.95).

Настольное приложение:

```sh
cargo run --release
```

WASM-страница:

```sh
rustup target add wasm32-unknown-unknown
cargo install trunk --locked
trunk serve
```

Открыть **http://127.0.0.1:8080**. Для удобства разработки можно запускать `cargo run` без `--release`.

Готовая статическая страница:

```sh
trunk build --release
python3 -m http.server 8080 --directory dist
```

Каталог `dist/` можно разместить на статическом хостинге, в том числе GitHub Pages. Пути к ресурсам относительные; страница работает в подкаталоге. Открытие `index.html` через `file://` не подходит для WASM.

macOS `.app`:

```sh
sh scripts/bundle-macos.sh
open target/release/Sugarscape.app
```

Приложение собирается для архитектуры текущего компьютера, без подписи для распространения.

## Публикация на GitHub Pages

Workflow `.github/workflows/check.yml` при каждом push и pull request проверяет форматирование, запускает тесты и собирает WASM. После успешных проверок изменения ветки `main` автоматически публикуются на **https://olegdurandin.github.io/growing-artificial-societies/**. При pull request выполняется только проверка и сборка.

В настройках репозитория **Settings → Pages → Build and deployment → Source** выбран **GitHub Actions**. Для повторной публикации без изменений доступен ручной запуск **Actions → Check and publish WASM → Run workflow**. Собранный сайт также доступен как артефакт `sugarscape-web` в каждом запуске workflow.

## Управление

- Вверху отдельно выбираются **глава** и **эксперимент внутри главы**. Смена главы запускает её первый опыт; любое переключение создаёт новый мир на паузе.
- Справа расположены ползунки параметров, по аналогии с NetLogo. Ширину панели можно менять мышью, перетаскивая её левую границу. Кнопка **«Применить и начать заново»** применяет изменения с полным сбросом. Отображение меняется сразу.
- **Запуск / Пауза**, **Шаг**, **Сброс**, скорость от 1 до 100 шагов/с. Пробел переключает паузу, `N` выполняет один шаг.
- Щелчок по агенту включает наблюдение за ним и подсветку области зрения. Наведение показывает данные участка.
- Вкладки **Карта мира**, **Динамика**, **Правила модели**. На узком экране параметры доступны кнопкой вверху.
- Цвет агентов: одинаковый, запас, зрение, метаболизм, пол или культурная группа. Для числовых шкал голубой означает минимум, малиновый — максимум. Шкала запаса нормируется по текущему самому богатому агенту.

## Эксперименты

| Опыт | Правила | Что наблюдать |
| --- | --- | --- |
| Мгновенное восстановление | G∞ + M | Расселение и отбор при полном восстановлении ресурса |
| Ограниченный ресурс | Gα + M | Конкуренция и численность выживших |
| Жизнь и смерть | Gα + M + R | Голод, старение и замещение новыми случайными агентами |

В главе **Sex, Culture and Conflict** доступны:

| Опыт | Правила | Что наблюдать |
| --- | --- | --- |
| Половое размножение | Gα + M + S | Демография, фертильность, наследование признаков при рождении |
| Передача культуры | Gα + M + S + K | Изменение культурных строк и состава групп |
| Межгрупповой конфликт | Gα + C + S + K | Борьба за ресурс, добыча и потери |

В новой главе все три опыта включают старение и половое размножение, **без автоматического замещения умерших**. Начальная популяция задаёт только стартовое число агентов.

В первых двух опытах главы Life and Death нет смерти от старости и нет замещения. В её третьем опыте умершие заменяются после всех движений; численность поддерживается постоянной. Замещение не является половым размножением.

## Принятые правила

1. Решётка по умолчанию 50×50. Участок содержит сахар от 0 до своей ёмкости. Две вершины построены процедурно. **Это учебный ландшафт, а не точная копия карты книги.**
2. В начале шага ресурс восстанавливается до ёмкости либо на α единиц с ограничением ёмкостью.
3. Агентам назначается новый случайный порядок каждый шаг. Видимость — четыре осевых направления без диагоналей; другие агенты не препятствуют обзору. Тор включён по умолчанию; можно включить закрытые границы.
4. Среди своей и свободных видимых клеток агент выбирает максимальный сахар, затем минимальное расстояние, затем случайный вариант. На торе используется кратчайшее осевое расстояние. При равном сахаре в своей клетке агент остаётся.
5. Агент собирает весь сахар и вычитает метаболизм. Нулевой запас означает смерть. Сахар погибшего исчезает из системы.
6. Зрение равномерно из целых `[1, максимум]`, метаболизм — `[1, максимум]`, начальный запас — `[5, максимум]`. В опыте R срок жизни равномерно из заданного интервала; смерть наступает при достижении предела. Начальный возраст — 0.
7. Новые агенты получают новые идентификаторы и случайные характеристики, размещаются на свободных клетках после всех движений, начинают действовать на следующем шаге.
8. Джини вычисляется по запасам живых агентов. При пустой популяции средние и Джини равны 0. История хранит последние 1001 состояние, включая начальное, пока оно не вышло из окна.

**Воспроизводимость:** SplitMix64, целочисленные правила, фиксированная последовательность случайных выборов. Одинаковые параметры и seed дают одинаковую симуляцию на native и WASM; скорость отображения не влияет на траекторию. Слишком большая начальная популяция ограничивается количеством клеток.

Учебная реализация охватывает правила M, G, R, S, K и C. Сезоны, загрязнение и наследование имущества после смерти пока не включены. Параметры и карта описаны явно, чтобы не выдавать результаты за точную репликацию экспериментов книги.

## Sex, Culture and Conflict: принятые соглашения

Порядок шага: G → движение/конфликт и потребление/смерть → K → S. Движение и культура выполняются последовательно в случайном порядке; в S каждая соседняя пара проверяется один раз, также в случайном порядке. Новорождённые не действуют в шаг своего рождения. Все исходные агенты имеют возраст 0.

- **S:** родители — соседи по четырём направлениям, разных полов, с запасом не ниже собственного начального и в возрастном окне. По умолчанию начало фертильности 15, конец для женского пола 40, для мужского 50. В каждой подходящей паре при наличии свободного участка у одного из родителей рождается ребёнок. Каждый родитель перечисляет половину своего начального запаса с округлением вверх; общий сахар сохраняется. Начальный запас ребёнка равен сумме взносов. Если после взноса родитель остался бы без сахара, рождение не допускается.
- Зрение и метаболизм ребёнка независимо берутся от одного из родителей; каждый культурный бит — тоже. Пол выбирается по заданной доле женского пола (по умолчанию 50%), срок жизни — случайно из заданного диапазона. Родительские ID и поколение доступны в инспекторе. Один агент может иметь нескольких детей за шаг с разными соседями.
- **K:** строка культуры содержит нечётное число битов (по умолчанию 11). Большинство 0 — синяя группа, большинство 1 — красная. Каждый агент копирует случайный свой бит каждому осевому соседу; по умолчанию одна попытка на соседа. Настройка 0 отключает обмен. При нескольких попытках один бит может выбираться повторно. Ползунок длины нормируется к нечётному числу при применении. Разделённый старт задаёт нули слева и единицы справа, иначе биты случайные.
- **C:** потенциальные жертвы — строго более бедные члены другой группы в осевом поле зрения. Награда — сахар участка плюс ограниченная лимитом доля запаса жертвы. Равенство награды разрешается расстоянием, затем случайно. Убийство удаляет жертву немедленно; она не получает дополнительного хода. При смерти от голода, старости и в конфликте имущество не наследуется.
- **Проверка возмездия:** используется осевое поле зрения нападающего с центром в целевой клетке. Если в нём остаётся враг, чей запас больше запаса нападающего плюс награда до вычета метаболизма, цель исключается. Это явно выбранное соглашение данной учебной реализации. Небезопасные свободные клетки также исключаются; текущая клетка остаётся запасным вариантом.

Смерти классифицируются взаимоисключающе: конфликт удаляет жертву сразу; после хода сначала проверяется голод, затем возраст. Счётчики рождений и потерь накопительные; состав культурных групп и число фертильных агентов считаются по текущему состоянию. Число фертильных — агенты подходящего возраста и достатка, а не число гарантированных родителей.

Источник для сопоставления правил — [Kehoe, разделы 3.12, 3.14 и 3.15](https://arxiv.org/html/1505.06012v3). Карта, округление взносов, порядок фаз, строгое сравнение достатка и проверка возмездия зафиксированы выше как соглашения реализации. Для точной репликации конкретного опыта книги понадобятся соответствующие карта и параметры.

## Структура и проверка

- `src/model.rs` — независимая от графики модель и тесты правил.
- `src/model/social.rs` — размножение, культура, конфликт и тесты новой главы.
- `src/app.rs` — общий интерфейс egui.
- `src/main.rs` — native / WASM запуск.
- `index.html`, `Trunk.toml` — веб-оболочка и сборка.

```sh
cargo fmt --all --check
cargo test --locked
cargo check --locked --target wasm32-unknown-unknown
```

Тесты проверяют повторяемость, уникальность позиций, ограничения ресурса, движение и приоритет расстояния, отсутствие диагонального зрения, голод, старение, замещение, топологию и Джини; для новой главы — условия рождения, сохранение сахара, наследование признаков, передачу культуры, ограничения нападения и риск возмездия. Проверка повторяемости охватывает все шесть опытов.
